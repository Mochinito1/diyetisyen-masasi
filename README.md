# Diyetisyen Masası

Diyetisyenler için kalori ve besin hesaplama, menü planlama aracı. Eğitim projesidir.
Veriler yalnızca tarayıcıda (localStorage) saklanır. **Gerçek danışan verisi girmeyin.**

## Geliştirme

```bash
npm install
npm run dev
npm test
npm run build
```

## Yayın

`main` dalına her push, GitHub Actions ile GitHub Pages'e yayınlanır.
Repo ayarlarında **Settings > Pages > Source: GitHub Actions** seçili olmalı.

Eski tek dosyalı sürüm: `docs/legacy/index.html`
